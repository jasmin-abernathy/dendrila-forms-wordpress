# Suite du développement

1. **Pilote WordPress isolé** : installer le ZIP, vérifier activation/dbDelta/WP-Cron et shortcode sur page publique sans cache. Vérifier mobile, clavier, lecteur d'écran et navigateurs.
2. **Parcours éditorial** : écran d'administration visuel pour organiser questions, thèmes, types et conditions sans éditer JSON.
3. **Réponses** : recherche et lecture sécurisée côté administration, exports paginés, révisions, purge manuelle contrôlée.
4. **Interviews** : invitations nominatives, authentification par code à usage unique, consentement, image avec crédit, étapes de validation avant publication.
5. **Enquêtes** : tableaux agrégés, contrôle des effectifs, exclusion de questions sensibles, audit anti-réidentification.
6. **Intégrations** : bloc Gutenberg, compatibilité thème et constructeurs, import/export modèles, traductions, politique de confidentialité paramétrable.
7. **Avant WordPress.org** : audit de sécurité externe, Plugin Check, essais d'accessibilité, documentation RGPD, mise à jour de la description principale de `readme.txt` pour chaque fonction publiée.

Ne jamais publier un fichier ZIP ou un site pilote comme étant prêt pour des données sensibles avant validation de ces étapes.
